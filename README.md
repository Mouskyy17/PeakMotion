# PeakMotion

 Détection et analyse des mouvements signature de joueurs professionnels (FC Barcelone) sur des séquences vidéo de matchs réels
• Tracking de joueurs en temps réel avec RT-DETR (Real-Time Detection Transformer) ; extraction de keypoints et classification 
de patterns de mouvement
• Application au scouting data-driven : quantification objective des gestes techniques récurrents par joueur
